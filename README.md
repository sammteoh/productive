# Task Manager
An interactive task manager application for daily to-dos

## Technologies
- `JavaScript`
- `HTML/CSS`
- `Node.js`

## Features
- Tasks are created by clicking the bottom of the list
- Tasks are intuitively editable on click and enter
- Lists are created through the input box
- Data is read from and stored in a CSV file

## The Process
I wanted to create a simple and minimalistic to-do list application to manage my daily tasks.

## Running the Project
- Clone the repository
- Install dependencies: `npm install`
- Run development server: `npm start`
